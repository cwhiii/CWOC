# Attachments

Any chit can have file attachments. The Attachments zone appears in the editor between Notes and Checklist.

- **Upload** — Click "Add Files" or drag and drop files onto the upload area. Multiple files can be uploaded at once
- **Download** — Click the download icon next to any attachment to download it
- **Delete** — Click the trash icon to remove an attachment (with confirmation)
- **Print** — Right-click (desktop) or long-press (mobile/app) a chit card on the dashboard and select "Print Attachment" to print a file directly. If the chit has multiple attachments, a picker lets you choose which one. Images and PDFs print natively; text files render as formatted text; other file types open a share/print dialog
- **Email Attachments** — Files attached to incoming emails are automatically saved during sync. They appear in the Attachments zone and as downloadable chips at the bottom of the email body. Right-click an attachment thumbnail in the email view for View, Download, or Print options
- **Indicator** — Chits with attachments show a 📎 icon on dashboard cards, calendar events, and other views
- **Size Limit** — Configure the maximum file size in [Settings → Email](/frontend/html/settings.html#email) Account → Attachments (5, 10, 25, or 50 MB)
- **All Attachments** — Visit `/attachments` to see every attachment across all chits in a visual grid. Supports multi-select (Shift+click for range, Ctrl/Cmd+click to toggle) and bulk delete
