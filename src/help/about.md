# About & Support

The [About page](/about) shows information about C.W.'s Omni Chits — what it is, who built it, and how to support the project.

## What's on the About Page

- **Version** — the current server version number
- **What is CWOC** — a brief overview of the app's core concept (the chit)
- **Buy Me a Coffee** — a link to support the developer
- **The Creator** — info about C.W. Holeman III with links to his website
- **Philosophy** — the design principles behind CWOC
- **Tech Stack** — the technologies used to build the app

## Buy Me a Coffee

CWOC is free and self-hosted. If you'd like to support ongoing development, the About page has a direct link to [Buy Me a Coffee](https://buymeacoffee.com/cwholemaniii).

## Accessing the About Page

- From any page, press <kbd>V</kbd> to open the Navigate panel, then select **About**
- Direct URL: [/about](/about)
