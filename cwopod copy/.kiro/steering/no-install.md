# No Software Installation

Under no circumstances should Kiro attempt to install any software, packages, dependencies, tools, or applications on this device. This includes but is not limited to:

- Running `npm install`, `pip install`, `brew install`, `apt install`, or any equivalent package manager install commands
- Installing global or local dependencies
- Installing CLI tools, SDKs, runtimes, or language versions
- Running setup scripts that install software
- Using `curl | sh`, `wget`, or similar patterns to download and install software

If a task requires software that is not already installed, inform the user and let them handle the installation themselves.
