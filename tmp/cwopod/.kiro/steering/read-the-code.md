# Read The Code First

## Rules

- When a new conversation starts and the user gives a task, READ the relevant code before asking questions.
- Look at the project structure, existing files, and related code to understand context.
- Use file search, grep, and directory listing to orient yourself before responding.
- Only ask clarifying questions if the code genuinely doesn't answer the question.
- Never ask "which file?" or "where is that?" if you can find it yourself by searching.
- Assume the user expects you to be familiar with the codebase. Explore first, ask later.
